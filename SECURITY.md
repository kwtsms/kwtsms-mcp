# Security

Report a vulnerability to support@kwtsms.com (subject: "kwtsms-mcp security"). Please do not open a public issue.

Supported: the latest release.

This server lets an AI model send SMS. The limits in the README (preview by default, live sending switched on by the
account owner, per-call, hourly and daily caps, fixed Sender ID) are enforced by the server, not by the model.
